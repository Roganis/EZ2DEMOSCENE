1Welcome

EZ2DEMOSCENE is a tool for making short, perfectly looping 3D animations in the style of the demoscene: glowing neon arenas, mirrored golden halls, glossy crystals orbited by debris, raymarched tunnels, kaleidoscopes and synthwave sunsets. The loops are for music visuals, VJ sets, wallpapers, social posts and GIFs.

You never write code or shaders. You pick a starting scene, then change it with sliders, colour pickers and menus. When you like it, you export an MP4, WebM, GIF or a folder of PNG frames.

The one big idea: everything loops

A scene is exactly a whole number of beats long, at a tempo you choose (BPM). Every motion in EZ2DEMOSCENE completes a whole number of times during that loop. That includes spins, orbits, pulses, particles, scrolling textures, drifting clouds and even film grain. So the last frame leads straight back into the first, with no jump.

Why this mattersYou never have to "fix the loop" by hand. Whatever you change, the export repeats seamlessly. This is why many settings ask for a count of turns per loop or cycles per loop rather than a speed.

How a scene is built

A scene is a stack of layers drawn together:

  • Background: the sky or environment behind everything (nebula, tunnel, plasma…).
  • Mirror floor: a reflective ground plane, optionally with a glowing grid.
  • Shapes: 3D objects, possibly copied many times in rings, grids, walls or swarms.
  • Particles: sparks, stars, glitter, vortices.

On top of the layers sit the camera, the light & fog, and the post effects that give the final look (glow, kaleidoscope, retro palettes, CRT…).

The easy way: download a release

Ready-made downloads are published on the project's GitHub Releases page for Windows, Linux and macOS. Unzip the archive and run ez2demoscene (ez2demoscene.exe on Windows). The Windows and Linux downloads include ffmpeg, so video and GIF export work straight away. On macOS, install it with brew install ffmpeg. The archive also contains this manual, the presets and the texture pack.

Building from source

git clone https://github.com/Roganis/EZ2DEMOSCENE
cd EZ2DEMOSCENE
cargo run --release                   # opens the editor
cargo run --release -- my.ez2.json    # opens a saved project

The first build downloads and compiles libraries, so it takes a few minutes. Later starts are instant. The finished program is target/release/ez2demoscene (ez2demoscene.exe on Windows), and you can copy it anywhere.

4Quick start: your first loop in five minutes

  1. Pick a preset. In the gallery, click Orbiting Solid. The scene starts playing straight away.
  2. Change a colour. Click the Dodecahedron layer on the left. In the inspector under Material, click the Colour swatch and pick a hot pink.
  3. Make it glow on the beat. Still in Material, find Glow and click the ~ button next to it. Set the wave to Pulse, amount to 3 and ×/loop to 8 (the loop is 8 beats long). It now flashes on every beat.
  4. Add particles. Click + Add → ✨ Particles → Vortex. In the new layer, set Colour (young) to white and Colour (old) to pink.
  5. Add a retro touch. Select Post effects on the left and tick Retro palette. Choose PICO-8.
  6. Export. Press Ctrl+E. Pick Animated GIF (the size switches to 480×270, a good size for GIFs), choose a file with Browse… and press ⏺ Export.
  7. Save your project with Ctrl+S to keep editing it later.
Made a mess?Ctrl+Z undoes any change, including randomizing and loading presets.

5Layers

The layer list works like the layers in a paint program. Each row has a visibility tick box and the layer's name. Click a row to edit it. Under the list, the buttons ⬆ ⬇ ⧉ 🗑 move, duplicate or delete the selected layer, and right-clicking a layer shows the same options.

5.1 Backgrounds

A background fills the whole screen behind the other layers and follows the camera. Every background has three colours (Colour A is usually the darkest), a Motion / loop count, a Brightness and a Detail (pattern scale).

Nebula cloudsSwirling fractal clouds with stars. The clouds drift on a closed path so they loop.

Raymarched tunnelThe classic demo tunnel flying forward through a winding tube. Pick a Wall texture (the XOR or checker textures are great).

5.2 Mirror floor

A large reflective ground plane. The scene is really reflected in it, including particles and the sky.

  • Reflection: 0 is matte, 1 is a perfect mirror. Blur gives a frosted, polished-stone look. Reflection tint colours the reflection (gold for a gold room).
  • Texture and Tiling put a pattern on the floor. The led_grid texture makes an LED dance floor.
  • Neon grid draws glowing lines. Set Grid glow, Grid colour, Grid scale and Scroll / loop (cells per loop) for the synthwave "driving" effect.
  • Floor height (in Placement & motion) moves the floor up or down.
One mirrorOnly the first mirror floor in the list reflects. Extra ones are ignored.

Variation (appears when there are copies) adds life:

  • Random tilt, Random size, Random hue and Random spin make every copy a little different. Change Seed to reshuffle them.
  • Size wave is a wave of growing and shrinking that travels across the copies.
  • Light chase is a bright glow running along the copies, like marquee lights.
  • Waves / loop sets how many times those waves pass per loop, and Wavelengths sets how many waves fit across all copies.

Colours across copies (also when there are copies) spreads 2–4 colours over them: Gradient blends smoothly (back to the first colour at the end), Steps gives each copy one colour in turn. Travel / loop makes the colours run along the copies; Colour the glow tints the glow too.

Deform

Bends the shape itself, on every copy. All values have ~, so they can move with the beat.

SettingMeaning
TwistTurns of twist from the bottom of the shape to its top.
BendCurves the shape into an arc (degrees from bottom to top).
TaperTop wider (+) or narrower (−) than the bottom.
WobbleBumps flowing over the surface; Bump size and Flow / loop tune them. Simple shapes need Subdivide (in Relief) for smooth bends and bumps.
ExplodeFaces fly apart, clearest with flat shading. Try ~ → Exp fade out, once per beat.

SettingMeaning

5.4 Symmetry

Symmetry copies the whole layer around the centre of the world:

  • Mirror X (left/right), Mirror Z (front/back), Mirror XZ (four copies).
  • Radial: N rotated copies around the vertical axis.
  • Kaleido: N copies where every other one is mirrored, giving a kaleidoscope pattern.
TipBuild one side of a room, then add Mirror X. The Gold Kaleido Room's orb walls, speakers and light panels are each built once and mirrored.

5.5 Particles

EmitterMotion
BurstExplodes outward from the centre.
Sphere driftFloats gently inside a sphere.
Ring orbitCircles in a flat ring (Speed = whole orbits per loop).
FountainShoots up and falls back.
Warp starsStreams towards the viewer (hyperspace). Add a Trail for streaks.
VortexSpirals upwards like embers.
Snow / glitterFalls slowly and sparkles.
TornadoSpirals up a swaying funnel that widens with height, with debris circling its foot. Use it with Smoke for a dark twister, or bright blue for a water spout.

Smoke makes particles cover what is behind them instead of adding light, so they can be dark (smoke, dust, a tornado). Brightness then becomes Opacity.

Count is the number of particles. Lives / loop is how many times each particle is reborn in one loop, so higher means faster. Area is the size of the emitter. The look is controlled by Sprite (soft glow, pixel square, star, ring), Size, two colours (young → old), Brightness and Trail (ghost copies behind each particle).

PerformanceParticles are cheap. Tens of thousands are fine on a normal GPU. Trails multiply the count, so count × (trail + 1) is what gets drawn.

5.6 Terrain

An endless landscape that rushes towards the camera, in the retro vector style. Add it with + Add → 🗻 Terrain.

SettingMeaning
StyleWireframe (glowing grid lines only; things behind show through), Solid (lit ground) or Solid + lines.
Height, Hills, RoughnessHow tall the mountains are, how many hills fit across the terrain, and how bumpy they are.
ValleyFlattens a road down the middle (0 = none), the classic synthwave look.
Scroll / loopHow many times the landscape scrolls past per loop. It repeats exactly, so the loop stays seamless. 0 stands still.
Line colour, Line glow, Ground colourThe look. Animate Line glow with a Pulse for beat flashes.
Texture, Tiles, Texture on lines, Chunky pixelsMaps a texture onto the ground (and optionally the grid lines). It moves with the landscape; Tiles is how many times it repeats across the terrain, a whole number so the loop stays seamless.
Size, Grid cellsIts extent and resolution. More cells is smoother but slower. Grid lines sit on every cell.
Level of detailFull resolution near the camera, gradually coarser further away, with no visible steps: a quarter of the triangles. Raise Grid cells (up to 512) or Size for sharper or bigger landscapes at the same cost. Distant ridges get slightly simpler.
ShapeHills (rolling), Ridged mountains (sharp crests), Mesas (flat terraces with cliffs), Sand dunes (gentle on one side, steep on the other), Canyons (a plateau cut by winding gorges) and Craters.
BiomeColours solid ground by height and steepness instead of one Ground colour: Alpine (grass, rock, snowy peaks, sandy shores), Desert (sand and banded red cliffs), Volcanic (black basalt with glowing cracks), Arctic (snow and blue ice), Alien (purple moss, teal crystal, glowing tips).

Water & lava

A Liquid fills everything below its Level with a flat surface. The level is a fraction of the mountain height; animate it for tides or rising lava. Liquids also show up on wireframe terrain.

LiquidLookShine / Glow, Ripples / Crust…
WaterReflects the sky with a sun glint, is lighter in the shallows and has foam and wet sand at the shore.Shine, Ripples
LavaGlowing rivers under a dark, cracked crust that drifts and churns. It lights up the nearby rocks.Glow, Crust
Toxic gooGlowing green slime with popping bubbles.Glow, Bubbles

Current / loop makes the surface drift along the terrain a whole number of times per loop; the ripples and crust also turn gently once per bar. Both loop exactly.

5.7 Laser beams

Club-style beams shooting from the layer's position along its up axis. Turn the layer with Rotation to aim them, and use Mirror X symmetry for a pair of laser rigs.

SettingMeaning
PatternFan (a flat fan that sweeps side to side), Rotating cone or Scatter (random directions that wobble).
Beams, Spread, Length, WidthHow many beams, how wide the fan or cone opens (degrees), and their size.
Colour (first/last)The beams blend from the first colour to the last.
Sweep, Sweeps / loopHow far the beams swing, and how often per loop (for the cone, also how fast it turns).

Set their Cone angle, and tick Light pools for bright spots where the cones hit the ground (height 0). Point the layer down (Rotation x 180) to hang the lamps from a ceiling. 5.8 Neon ribbon

A glowing tube along a closed curve, with pulses of light running along it. Choose a Curve (Lissajous, Knot, Figure eight, Wavy ring, Rose) and its wave counts, then set Pulses, Laps / loop (negative runs backwards), Pulse length and Pulse glow. Ribbons reflect in mirror floors and can take symmetry.

5.9 Weather

+ Add → ☔ Weather fills a box around the camera with rain, snow, embers, sand or fireflies. The box follows the camera, so the weather is everywhere you look. Its Ground height is where rain splashes and embers start.

SettingMeaning
KindRain (streaks and splash rings), Snow (swaying flakes), Rising embers (flickering sparks), Sandstorm (dust blown along the wind), Fireflies (wandering, blinking lights) or None (lightning only).
Amount, Size, Colour, BrightnessHow many drops and how they look. Rain also has Streak length and Splashes.
Falls / loopHow many times each drop falls per loop: higher is faster. It is a whole number, so the weather loops.
Wind, Wind directionSlants the rain and snow. Animate Wind with a Sine for gusts.
Area, HeightThe size of the box around the camera.
Wet ground / Snow coverRain makes every surface darker and glossier, with puddles on flat ground that mirror the sky and ripple with rain rings. Snow settles on everything facing up. A snow cover can't really build up over a loop (it would have to jump back at the end), but you can animate it, for example with a Swell so it builds up and melts away.
LightningJagged bolts that strike in front of the camera and a flash that lights up the whole scene, clouds included. Chances / loop and Chance decide how often; each strike flickers two or three times.
PerformanceWeather drops cost about as much as particles. Volumetric clouds are the heavy part of a storm scene: lower their Quality on phones.

5.10 Waterfall

+ Add → 🌊 Waterfall adds a curtain of water, lava or toxic goo that pours from the layer's position downwards and arcs out along its Z axis, with streaks running down it and foam, spray or smoke at its foot. Place it on the edge of a cliff: a terrain mesa, a shape or a wall of boulders (see the Rainbow Falls preset).

SettingMeaning
Width, Height, ArcThe size of the curtain and how far it arcs out from the edge.
Flow / loopHow many times the streaks run down per loop (a whole number, so it loops).
Brightness / GlowWater brightness, or the glow of lava and goo.
Foam & mist / SmokePuffs at the foot (0 = none).

5.11 Placing objects in the viewport

  • Select a shape or particle layer by clicking it in the viewport, or in the layer list.
  • Pick a tool above the viewport: Move (W), Rotate (E) or Scale (R).
  • Drag a handle. Red is X, green is Y (up) and blue is Z. With Move, the white circle in the middle slides the object along the floor. With Rotate, drag one of the three rings. With Scale, the coloured squares stretch one axis and the middle circle changes the overall size.
  • Hold Ctrl while dragging to snap: moves go in 0.25 steps, rotations in 15° steps and sizes in 0.1 steps.
  • Grid (G) shows the ground grid, where one square is one unit.
  • Dragging anywhere else still turns the camera, and the mouse wheel still zooms.
TipPause first (Space) when placing spinning or orbiting things. Every handle drag counts as a single step for Ctrl+Z.

6Materials, glow & textures

Surface

SettingEffect
ColourThe base colour.
Metallic0 looks like plastic or paint. 1 looks like metal, where reflections take on the colour (gold, chrome, copper).
Roughness0 is a glossy mirror-like finish, 1 is matte. The glossy black look of Neon Arena is black + metallic 0.9 + roughness 0.15.

Glow (emission)

Glow colour and Glow (strength) make a surface emit light. Bright glow feeds the bloom post effect and produces the neon halo. Glow where decides which part glows:

Glow whereResult
FullThe whole surface glows (neon tubes, light panels).
EdgesOnly the outlines of each face glow, for a Tron / wireframe-neon look. Works on the solids, panels, cylinders, shards and pyramids.
StripesGlowing horizontal stripes.
TextureBright parts of the texture glow (LED grids, circuits, tech-panel slits).

Hue shift rotates all the colours of the layer. Animate it with a Saw wave for rainbow cycling.

Relief: bump, normal and displacement maps

The Relief section of a shape layer makes its surface uneven. It uses the material's Tiling and Scroll, and the colour texture unless you pick a separate Relief texture.

SettingResult
Mode: BumpThe texture's brightness is height: bright parts look raised, dark parts sunken (mortar between bricks, rivets, grid lines). Only the lighting changes, so it's cheap.
Mode: Normal mapThe texture is a normal map (the purple-blue images from 3D tools and texture sites). Import one as an image and pick it as the relief texture.
ReliefStrength of the bump or normal map (animatable).
DisplacementReally moves the surface outwards by the texture brightness (negative pushes inwards). Animate it for pulsing, breathing shapes.
SubdivideAdds geometry detail (each level splits every triangle in four), so displacement can show fine patterns.
TipDisplacement looks best on smooth shapes (sphere, torus, capsule, rounded cube). Faceted shapes such as the cube or the gem open up at their edges, because each face moves along its own direction.

Glitch

The Glitch section of a shape layer corrupts its geometry, like a broken signal. Set an Amount and a Style:

StyleResult
JitterThe corners shake to random positions; the shape crumples without tearing.
Slices (VHS)Horizontal bands of the object jump sideways.
ShatterThe faces fly apart along their directions.

Changes / loop is how many new random patterns appear per loop, and Chance is how many of those moments actually glitch (1 = all the time, 0.3 = short bursts). Like everything else, the glitch pattern repeats exactly every loop. Animate Amount with a Pulse for hits on the beat.

Your own images & "retro-ize"

Import images (PNG, JPG, BMP, GIF, TGA) in any of these ways: from a texture menu (Import image…), from File → Import image…, or by dragging them onto the window. A dropped image is applied to the selected shape. All your images are listed under Your images, where you can tick Retro-ize. This shrinks the image to Max size pixels and remaps it to a classic Palette with Dithering, turning any photo into a 90s texture.

7Animating anything

Every value with a ~ button next to it can move over time. The button turns pink when the value is animated. Click it to open the animation panel:

ControlMeaning
WaveThe shape of the movement, in three groups (see below). Hover a shape in the menu for a description.
amountHow far the value moves from the slider value. 0 means not animated. Picking a shape or a rhythm on a still value gives it a starting amount so you see something straight away.
♩Rhythm menu: twice per beat, every beat, every 2 beats, every bar, every 2 or 4 bars or once per loop. It sets ×/loop for you from the loop length.
×/loopWhole cycles per loop. The number of beats in the loop hits every beat. Negative numbers run backwards.
offsetShifts the timing (0–1 of a cycle), to stagger several animations.
♪Adds the music's loudness (see chapter 10).

Below the controls, a small graph shows the value over the whole loop, with beat ticks and a dot at the current moment.

GroupShapesUse them for
LFOSine, Triangle, Saw up, Saw down, SquareSmooth or hard back-and-forth movement around the slider value.
Beat fadesPulse (hit), Exp fade in, Exp fade out, Linear fade in, Linear fade out, Swell in & outEnvelopes that run from 0 to the full amount (or back) once per cycle. Set ♩ → every beat for hits that decay (Exp fade out), build-ups that drop on the beat (Exp fade in), or breathing swells.
RandomSample & hold, Smooth random, Drunken walkA new random value each cycle (held, or gliding smoothly), or a random walk that wanders and always finds its way back by the end of the loop.

Almost every number can be animated this way, including post effects (bloom threshold, pixel size, dither, CRT scanlines and curvature, contrast, saturation, vignette, grain, beat flash, kaleidoscope angle), materials (metallic, roughness, rim light, tiling), light, camera swing and shake, particle speed and area, mirror reflectivity and blur, laser spread, length, width and sweep, terrain roughness and valley, and ribbon pulses.

Recipes

  • Pulse on every beat: Glow → Pulse, amount 3, ×/loop = loop beats (e.g. 16).
  • Breathing camera: Camera Distance → Sine, amount 2, ×/loop 1.
  • Kick zoom: Kaleidoscope Zoom → Pulse, amount 0.2, ×/loop 16.
  • Rainbow: Hue shift → Saw, amount 0.5, ×/loop 1.
  • Floating object: Bob → Sine, amount 0.5, ×/loop 2.
  • Strobe: Glow → Square, ×/loop 32.
  • Beat hit: Glow → Exp fade out, ♩ every beat.
  • Build-up: Bloom threshold → Exp fade in, ♩ every 4 bars (negative amount lowers it towards the drop).
  • Nervous camera: Camera Height → Drunken walk, ♩ every beat, amount 1.

Shake

Placement & motion → Shake jolts a layer in a random direction. Shake distance and Shake turn set how far, and New direction how many times per loop a new random direction is picked. Give the distance a fade for a hit that settles: the ⚡ Beat jolt button does exactly that (Exp fade out, every beat). The Jitter node can drive the same shake for everything connected to it (chapter 12).

Blink / strobe

Every layer has a Blink / strobe section that makes the whole layer appear and disappear, or flash:

ModeWhat it does
BlinkOn and off in a regular rhythm. On time is the fraction of each blink it stays visible.
Random blinkOn and off at random moments. Chance on sets how often it is visible.
FlashStays visible but its glow flashes and fades. Dim level is the brightness between flashes.

Times / loop sets the rhythm (16 = every beat of a 16-beat loop) and Offset shifts it, so two layers can blink in turn.

Light & fog

  • Fog colour / Fog density: distant things fade into this colour. The fog colour is also the "empty space" colour, so match it to your background.
  • Sky light / Ground light / Ambient: soft light from above and below. The sky colour is also what glossy surfaces reflect, which gives black gloss its highlights.
  • Sun colour, Sun strength, Sun direction: the main light.
  • Sun shadows: shapes and terrain cast shadows from the sun (the moon at night) onto shapes, terrain, water and the mirror floor. Darkness, Softness and Distance (how far around the camera's target shadows reach: smaller is sharper). In dark neon scenes shadows are subtle, because most light comes from glow, not the sun.
  • Contact shadows: soft dark patches under shapes standing on a mirror floor, so they don't look like they float.
  • Mist (height fog): fog that is thick near the ground and thins out higher up, so it pools in valleys and over water. Base height is where it is densest, Thickness how high it reaches. It also hides the horizon of the background.
  • Underwater caustics: the rippling web of light you see at the bottom of a pool, on every surface. Only below limits it to things under a water line.
  • Rainbow: a rainbow (with a faint second bow) opposite the sun. Like a real one, it needs the sun fairly low: with the sun high above, the bow sinks below the horizon.
  • Day & night cycle: the sun rises, crosses the sky and sets a whole number of times per loop. The light, fog and sky turn warm at sunrise and sunset; at night the sky darkens, stars come out, the moon rises opposite the sun and moonlight takes over. Sun direction sets where the sun is at noon. Clouds, god rays and reflections all follow the sun.

10Timing & music

Tempo and loop length

Tempo (BPM) and Loop length (in beats) set how long the loop is. For example, 128 BPM × 16 beats = 7.5 seconds. The quick buttons set 4, 8, 16, 32 or 64 beats. These values also appear in the timeline.

Because every animation is counted per loop, changing the BPM speeds the whole scene up or slows it down, and it stays in sync.

Adding music

Use Load music… or drop an MP3, WAV, OGG, FLAC, M4A or AAC file onto the window. The song is analysed once when it loads: loudness, kick, bass, mids, highs and brightness curves; the hits (kicks, snares and claps, hi-hats, any onset, new notes); a 16-band spectrum; the melody's note; and the tempo. The timeline shows the loudness, with kicks as red ticks and snares as yellow ones. The Meters show every source live. The analysis runs in the background (Analysing music… 42% in the viewport bar), so you can keep editing; music-driven settings start reacting when it finishes, and exports wait for it. Changing only the MIDI file or its offset reuses the analysis instead of starting again.

Loop a part of the song, or the whole song

  • Loop a part of the song (default): the loop reacts to a window of the song as long as the loop, starting at Starts at. The window is treated as a circle: the last moments fade into its start, and a hit near the end keeps ringing after the loop point, so the loop stays seamless. Video exports contain exactly that window of the song, repeated. Use song tempo sets the BPM to the detected tempo and snaps the window onto a bar; Snap to bar only snaps; Fit whole song makes the whole track one loop.
  • Whole song: the preview and exports run from the start to the end of the song (repeats don't apply); loop animations keep cycling underneath.

Making values react: the 🎵 row

Every ~ panel has a 🎵 row under the rhythm settings. Pick a source and an amount:

SourceWhat happens
Follow: Loudness, Kick, Bass, Mids, Highs, BrightnessThe value rises with that part of the sound. Tick smooth for a calmer curve and use ignore below to react only to the loud parts.
Follow: Melody pitchThe melody's note from C (0) to B (11/12). On Hue shift with amount 1, each note gets its own colour.
Each kick / snare / hi-hat / hit / new notePlays a shape (a beat fade, e.g. Exp fade out) of the chosen length in beats on every hit, scaled by how hard it hit. Flashes on the song's real kicks rather than on the metronome.

A negative amount pulls the value down instead (e.g. the camera distance on each kick, for a punch-in). The curve preview shows the result with the music.

Time warp

Time warp makes motion (spins, orbits, camera moves, scrolling, clouds, LFOs) run faster while the chosen source is strong, so the scene surges on every kick or on the loud parts. The warped time is rescaled so a full loop still ends exactly where it started, so the loop stays seamless. Beat fades, strobes, blinks and shakes stay on the real beat. A negative amount slows motion down on hits.

Equalizer copies

Shapes with copies have an Equalizer setting (under Copies → variation): each copy grows upwards and glows with one frequency band, low notes first. 16 copies in a row or an arc make a classic spectrum display (see the Music Reactor preset).

MIDI notes

Load MIDI notes… (or drop a .mid file) takes the hits and the melody from a MIDI file instead of guessing them from the audio: drums on channel 10 give exact kicks, snares and hats, other channels give new notes and the melody pitch, with their velocities. MIDI offset lines the notes up with the audio. A MIDI file works without an audio file too.

Live input

Live input (microphone / line-in) makes the preview react to what the microphone hears, for VJ sets. Every source works live, and so does time warp. Live input is not repeatable, so exports always use the music file.

Tip for musiciansLoad your track, press Use song tempo, pick a strong section with Starts at, then link the glow of your shapes to Each kick. Export with the music included and the visuals land exactly on your beats.

11Randomize, Surprise me & undo

  • 🎲 Randomize shuffles the current scene: one harmonious hue rotation of all colours, new shapes and layouts, new motion and a few post-effect changes. Every click gives a new variation.
  • ⚙ opens the Randomizer settings. Choose what may change (Colours, Shapes & layouts, Motion, Post effects), how strongly, and the seed. The same seed always gives the same result.
  • Surprise me picks a random preset and randomizes it strongly.
  • Undo / redo (Ctrl+Z / Ctrl+Shift+Z) covers everything, so randomize freely.

Click Nodes in the top bar to build the scene as a graph. Layers become source nodes that flow through modifiers into an Output. Everything connected to Output is rendered.

NodeWhat it does

Working with the graph: right-click empty space to add nodes, drag from an output dot to an input dot to connect, and right-click a node to Duplicate or Delete it. The toolbar has three controls: render the graph switches between the graph and the plain layer list; Rebuild from layers starts a new graph from your layers; and Bake to layers turns the graph's result into ordinary layers and returns to Simple mode.

Signals: wire any setting to a wave, a beat or the music

Besides layers, wires can carry signals: one number that changes over the loop. Signal pins are green (outputs are squares). A signal node shows a small graph of its value over the whole loop, with the current moment marked in pink. Add them from the right-click menu under Signal.

Signal nodeWhat it does
Wave / musicAny animation: a wave with whole cycles per loop, a fade on every beat, random steps, or a link to the music (follow the kick, bass or melody, or react to hits). It uses the same ~ and 🎵 controls as every other value.
MathA + B, A − B, A × B, A ÷ B, the smaller or larger one, or A > B / A < B (1 or 0). Unconnected inputs use the numbers typed in the node.
RemapMaps one range to another, e.g. −1…1 to 0.7…1.35. stay in range clamps.
QuantizeRounds to steps (4 steps per 1 → 0, 0.25, 0.5…).
SmoothAverages over a few beats around each moment. Great on random steps. Music links have their own smoothing (the 🎵 row), which works better for them.
MixBlends A to B by T.
SequenceSteps through your list of values, one every N beats, starting over with the loop. glide slides from each value to the next.
Hit counterCounts kicks (or snares, hats, any hit, notes) since the start of the loop: 0, 1, 2… up to count to − 1, then starts again. Through a Remap (0…3 → 0…1) it steps a setting on every kick.

A Drive node puts a signal to work. Wire layers into its first input and a signal into the second, then pick the setting from the list: kind.… are the layer's own settings (for a shape, kind.material.emissive is its glow), transform.… its placement, and .0 .1 .2 are x, y, z (or red, green, blue). Choose how the signal is used: set to replaces the value, add adds to it (the setting keeps its own animation), and multiply by scales it. Chain Drive nodes to drive several settings.

Signals are worked out from the loop position and the music at that moment, so graphs always loop seamlessly. The Signal Flow preset shows a stepped glow Sequence and a smoothed random size on the centrepiece. Bake to layers drops the Drive nodes (settings keep their own values).

14Saving, sharing & your library

Project files

File → Save (Ctrl+S) writes a .ez2.json project. Models, images and music stored inside the project's folder (or its sub-folders) are remembered relative to the project. You can move or copy the whole folder, even to another computer, and everything is still found. Files elsewhere on your disk are remembered by their full path.

Packs: one file with everything

File → Save as pack (.ez2pack)… writes a single file containing the project and copies of every model, image and music file it uses. It's the best way to send a scene to a friend or archive it. Open a pack with File → Open… or by dropping it on the window. It is unpacked into your library folder, and Save then asks where to keep the project. If some files were missing when packing, the status bar lists them.

Autosave & crash recovery

While you work, unsaved changes are autosaved every 30 seconds. If the program or computer crashes, the next start offers to recover them:

After recovering, save the project somewhere with Ctrl+S. When you quit normally, the autosave is deleted.

My presets

File → Save as my preset… adds the current scene to the gallery with a thumbnail of the current frame. Find it under Presets → My presets. Clicking one opens it as a new untitled project, so your preset is never overwritten by accident. The 🗑 delete button removes it.

Layer templates

Built a great particle effect or neon ring? Right-click the layer → Save as template. It then appears in + Add → ⭐ My templates in every project, and also in the node graph's right-click menu. Manage your templates in Presets → My layer templates.

Where is my library?Your presets, templates, unpacked packs and autosave live in your user data folder: %APPDATA%\ez2demoscene\EZ2DEMOSCENE\data on Windows, ~/.local/share/ez2demoscene on Linux, and ~/Library/Application Support/org.ez2demoscene.EZ2DEMOSCENE on macOS. Copy it to back everything up.

Performance

The small fps number above the viewport shows how smoothly the preview runs. It turns orange below 24 fps. A ⚠ next to a layer in the list marks a heavy layer. Hover it for details. The usual fixes are fewer copies, less sphere detail, fewer particles or a shorter trail. You can also lower the preview quality, which only affects the preview and never your exports. Volumetric clouds and the raymarched backgrounds are the heaviest layers; their Quality setting trades detail for speed.
